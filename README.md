# xSamir Portfolio

A modern, high-performance portfolio website built for **Samir Gaihre (xSamir)** using Next.js 14+ (App Router), Tailwind CSS, and TypeScript.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ installed

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/sg61x/xsamir-portfolio.git
    cd xsamir-portfolio
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Tech Stack

-   **Framework**: [Next.js](https://nextjs.org/) (App Router)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Icons**: [Lucide React](https://lucide.dev/)
-   **Theme**: [next-themes](https://github.com/pacocoursey/next-themes) (Dark/Light mode)
-   **Deployment**: Vercel Ready

## 📂 Project Structure

-   `src/app`: Application routes and pages.
-   `src/components`: Reusable UI components.
-   `src/lib`: Utility functions and static data (projects.json).
-   `public/assets`: Static images and assets.

## 🌍 Deployment on Vercel

The easiest way to deploy your Next.js app is to use the [Vercel Platform](https://vercel.com/new).

1.  Push your code to a GitHub repository.
2.  Import the project into Vercel.
3.  Vercel will detect Next.js and deploy automatically.
4.  Your site is live!

NO extra configuration needed.

## 🎨 Customization

-   **Projects**: Edit `src/lib/projects.json` to update your portfolio items.
-   **Theme Colors**: Edit `src/app/globals.css` to change the CSS variables for colors.
-   **Content**: Update text in individual page files in `src/app`.
